The pill button classes from the shared stylesheet, for markup without React.

**Classes:** `.btn-dark` (pine-deep fill, cream text; hover pine, lift, `shadow-button-hover`), `.btn-ghost` (transparent, hairline border; hover ink border), `.btn-paper` (paper fill, pine-deep text, for dark bands), `.btn-outline-paper` (translucent cream border on dark bands).

- All: full radius, 44px min height, 15px/600 Inter, 180ms transitions.
- One `.btn-dark` per view. On a `pine-deep` band, use `.btn-paper` as the primary.
