The signature headline: Playfair Display 600 with an italic pine phrase, often on two lines.

**Usage:** `<h2 class="display-heading text-display">Your in-between years<br><em>are a tax opportunity.</em></h2>`. `.display-heading` sets -0.015em tracking and 1.06 leading; `<em>` turns italic `pine`.

- One per section. The plain phrase states the idea; the pine phrase lands it.
